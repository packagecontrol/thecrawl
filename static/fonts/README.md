# Vendored web fonts

These files are vendored from Google Fonts for local serving.

- Lato v25: normal 400/700 and italic 400/700
- IBM Plex Mono v20: normal 400/700

The CSS in `../style/fonts.css` keeps Google Fonts' unicode-range split so
browsers only request the subset needed for the current page.
